2. MAHSULOTLAR KATALOGI (Products Catalog) — "/products"
   - Chap panelda filtrlar:
     * Zavod bo'yicha (GET /factories dan oladi)
     * Sirt turi bo'yicha (GLOSSY / MATTE)
     * Qo'llanilishi bo'yicha (Hammom, Sanuzel, Zal)
     * O'lcham bo'yicha (60x60, 30x60, 60x120)
     * Qidiruv matni (kod, nom, rang)
   - O'ng tomonda mahsulotlar grid (GET /products dan oladi)
   - Sahifalash (pagination)
   - Saralash (narx bo'yicha, yangilik bo'yicha)

3. MAHSULOT BATAFSIL SAHIFASI (Product Detail) — "/products/[id]"
   - Katta rasm (mainImage) + galereya rasmlari (GET /gallery/product/:id)
   - Mahsulot nomi, kodi, narxi
   - Xarakteristikalar jadvali:
     * O'lcham (size)
     * Qalinlik (thickness)
     * Rang (color)
     * Sirt turi (surface: GLOSSY/MATTE)
     * Qo'llanilishi (usage)
     * Quti hajmi m² (boxSize)
     * Ombor qoldig'i (stock)
   - Zavod ma'lumoti (factory nomi, joylashuvi)
   - "Savatga qo'shish" tugmasi (miqdor tanlash bilan)
   - O'xshash mahsulotlar (Related Products)
   - Bitgan ishlar galereyasi (GalleryImages — xona turi bilan)

4. BIZ HAQIMIZDA (About Us) — "/about"
   - Kompaniya tarixi va maqsadi

  GET  /factories/:id          — Bitta zavod + uning mahsulotlari
  GET  /products               — Kafellar katalogi (filtr, qidiruv, sahifalash)
  GET  /products/:id           — Bitta kafel to'liq ma'lumot
  GET  /products/code/:code    — Kod bo'yicha qidiruv
  GET  /gallery/product/:id    — Mahsulot galereya rasmlari
  POST /auth/login             — Tizimga kirish

YOPIQ (Admin) API'lar — JWT token kerak:
  GET  /auth/me                — Profil olish
  POST /auth/register          — Yangi admin/menejer
  POST /products               — Mahsulot qo'shish
  PATCH /products/:id          — Mahsulot tahrirlash
  DELETE /products/:id         — Mahsulot o'chirish
  GET  /products/admin/all     — Admin uchun barcha mahsulotlar
  POST /factories              — Zavod qo'shish
  PATCH /factories/:id         — Zavod tahrirlash
  DELETE /factories/:id        — Zavod o'chirish
  POST /gallery                — Galereya rasm qo'shish
  DELETE /gallery/:id          — Galereya rasm o'chirish
  POST /upload/image           — Rasm yuklash (multipart/form-data)
