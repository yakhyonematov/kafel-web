13. ANIMATSIYALAR VA SMOOTH EFFEKTLAR
================================================================================

UMUMIY QOIDALAR:
  - Barcha transition: 0.2s — 0.3s ease (tezkor, lekin silliq)
  - Juda sekin animatsiya bo'lmasin (UZB mijoz sabrsiz)
  - Animatsiya maqsadli bo'lsin (har narsa uchun emas)

TRANSITION TOKENLAR:
  --transition-fast:     0.15s ease
  --transition-base:     0.25s ease
  --transition-slow:     0.35s ease
  --transition-smooth:   0.4s cubic-bezier(0.4, 0, 0.2, 1)

HOVER EFFEKTLAR:
  Kartochka:
    transform: translateY(-4px)
    box-shadow: kuchayadi
    transition: all 0.3s ease

  Button:
    transform: translateY(-1px)
    shadow: paydo bo'ladi
    transition: all 0.2s ease

  Rasm (kartochka ichida):
    transform: scale(1.05)
    transition: transform 0.4s ease
    overflow: hidden (container)

  Navbar link:
    color o'zgaradi: 0.2s ease
    pastki chiziq: width 0% -> 100%, 0.25s ease

SCROLL ANIMATSIYALARI:
  Sahifa elementlari ekranga kirganda:
    opacity: 0 -> 1
    transform: translateY(20px) -> translateY(0)
    transition: 0.5s ease
    Staggered delay: har bir element 0.1s kechikish bilan

MODAL/DRAWER ANIMATSIYALARI:
  Drawer (savat):
    O'ng tomondan sirpanib chiqadi
    transform: translateX(100%) -> translateX(0)
    transition: 0.35s cubic-bezier(0.4, 0, 0.2, 1)
    Overlay: opacity 0 -> 0.5, bg: rgba(0,0,0,0.5)

  Modal:
    Markazdan paydo bo'ladi
    opacity: 0 -> 1
    transform: scale(0.95) -> scale(1)
    transition: 0.25s ease

LOADING HOLAT:
  Skeleton:
    background: linear-gradient(90deg, #F0ECE6 25%, #F8F6F3 50%, #F0ECE6 75%)
    background-size: 200% 100%
    animation: shimmer 1.5s infinite
    border-radius: kartochka bilan bir xil

MICRO-INTERACTIONS:
  "Savatga qo'shish" bosilganda:
    - Tugma qisqa vaqt "Qo'shildi" ga o'zgaradi (yashil)
    - Savat ikonkasidagi badge raqam +1 bo'ladi (kichik bounce animatsiya)
    - Toast bildirishnoma paydo bo'ladi (pastdan yuqoriga sirpanib)

  Accordion (FAQ) ochilish:
    - Chevron 180 deg aylanadi: transition: 0.3s ease
